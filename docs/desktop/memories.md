# 跨会话记忆

设置中的「跨会话记忆」管理当前 Windows 用户的本机记忆。使用开关和自动生成开关分别保存，初始均关闭。用户范围用于全部聊天；项目范围只用于该项目，包括其 Worktree。没有项目的聊天只取得用户范围的已确认内容。

可以手动创建、编辑、停用和删除记忆。模型生成的内容先保存为待确认候选，确认后才能用于对话。来源保留聊天标识、消息标识、模型和生成时间。编辑使用版本检查，其他窗口的修改不会被过期草稿覆盖。

生成调用所选聊天配置的真实模型，只处理最近一百条用户消息中最多三万字的可用文字。不加载工具、MCP、插件、项目指令或附件。文件引用、工具输出、代码块、已知凭据和疑似秘密会排除；模型输出再次过滤，并校验来源标识。没有可提取内容时保留空结果，不伪造记忆。

自动生成只在普通聊天成功结束后启用。该功能会向该聊天配置的供应商发送经过过滤的文字；它不使用独立云记忆服务。运行配置与凭据在主进程创建一致快照。进度、取消、失败和重启中断显示在设置页面，原对话不被中断。

主进程每次模型轮次开始时返回当前已启用的确认记忆，作为历史上下文，不能扩大任务权限或覆盖当前请求。关闭使用开关和删除会影响后续轮次；已经发出的模型请求和原始聊天内容不被撤回或改写。

记忆保存在独立 memories.json，原子替换且不创建会复活已删除正文的轮换备份。删除保留不可逆摘要以防再次提取相同内容和来源；原始聊天继续保留。清除全部会取消正在生成的候选。生成期间其他记忆操作使旧结果失效，必须重试。损坏或未来版本不会被静默清空，用户可以恢复文件或明确清除全部记忆。

## 接续迭代：运行与清除恢复（2026-09-29）

准备阶段先登记进度与取消入口，来源及记忆修订在请求开始时固定；模型输出必须完整结束且不含工具调用。队列及临时写入阶段响应取消，失败不会标记来源已处理，重启后可重试。清除确认绑定打开时的版本，拒绝包含后来新增内容的过期确认；删除失败保留原确认与即时双语原因。完整命令、失败复现及验收边界见 [记忆运行恢复](memory-runtime-recovery.md)。下方设置迭代记录保留，不替代本轮证据。

## 接续迭代：设置恢复与草稿保护（2026-09-29）

- 保存、删除、清除、生成和取消使用同步操作锁，连续点击不会重复发出请求。保存期间阻止离开设置；失败保留草稿，重试成功后解除导航保护。其他设置偏好与正在运行的聊天不受影响。
- 已确认的保存与后续列表读取分开反馈。保存成功立即关闭编辑器并展示返回的记忆；列表读取失败只提供读取重试，不再把已保存内容当作待创建草稿。已确认的删除也立即移出列表。
- 刷新保留当前列表并显示读取状态。过期请求、隐藏页面的迟到响应和旧版本快照不能替换当前内容；格式错误显示简短双语说明，不输出解析器细节。手动刷新只发起一次读取。
- 其他窗口修改或删除正在编辑的记忆时，保留本地草稿并阻止过期保存。加载最新版本需要明确确认，Escape 或取消继续保留草稿。切换设置分类不清空记忆草稿。
- 新失败记录不会遮掉仍在运行的记忆生成；取消入口保留，取消失败可以重试。编辑完成、取消及读取重试成功后恢复可操作的键盘焦点。
- 沿用现有布局，未增加常驻工具栏入口；冲突提示与重试控件按需显示。
