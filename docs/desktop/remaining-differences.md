## 工程边界

MCP 的“已连接”来自实际握手及工具发现，错误/关闭来自传输或 worker 生命周期事件；没有增加后台探活、自动重连或远端 HTTP 服务健康保证。最后工具列表仅作历史展示，连接断开时不作为当前可执行能力。测试与任务连接相互独立，第三方 OAuth 或任意 MCP 服务的完整兼容性未纳入本地假服务验收；未记录第三方 stderr 或密钥内容。

资源源文件检查遵循 SDK 现有 Skill 解析规则，扩展检查限路径与可读性，不静态证明其模块语法、外部依赖或执行成功。任务加载记录是初始化运行环境时的实际结果，不是持续健康监测；资源变更需刷新并在下一次运行重新创建环境。未用真实第三方扩展组合建立完整兼容性保证。

文件编辑综合验收在摘要增量轮次出现一次冲突后重载再保存未落盘：原磁盘内容保留，失败清理另有原生对话框协议错误。8 次独立重跑及同一编辑器 20 次、200 次连续循环未复现；临时诊断已移除，原因尚未确认。后续完整回归结果见 workbench-acceptance.md；即使复验通过，也不据此声称该间歇失败已修复。
