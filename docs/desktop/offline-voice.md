# 本地离线语音

## 使用

设置 → 离线语音：选择持久模型目录，保存后下载或导入固定模型。SenseVoice 与 Silero 用于听写，Kokoro 用于朗读。下载显示真实字节进度；导入只接受下列版本的原始文件。模型目录不属于临时缓存，已有模型时不能直接切换目录。

输入框麦克风开始听写，“停止录音并识别”将文字追加到现有草稿，保留附件，不自动发送。波形按钮明确确认后开启语音对话：录音 → 检测停顿 → 本地识别 → 当前 Pi 供应商回答 → 本地朗读 → 下一轮。草稿、附件或上下文引用未处理时不自动发送。用户中途输入或另发消息会终止自动循环，并保留识别文字。

可选择输入设备、中文/英文/自动语言、音色与语速；可随时取消录音、识别和合成，停止朗读。停止语音不会停止模型任务。切换聊天、离开聊天页面、关闭所属窗口或退出应用会结束语音，不在重启后恢复麦克风。

## 真实执行与边界

- sherpa-onnx-node@1.13.8，Windows x64 原生绑定，独立 Electron utility process，CPU 推理。ASR/TTS 两线程，VAD 一线程。取消同步推理时结束专用进程，不影响任务 worker。
- AudioWorklet 将录音转成 16 kHz 单声道，半秒分块，有排队上限和两分钟录音限制；录音、中间数据和朗读 WAV 都仅在内存中。只把识别文字交给现有聊天模型。
- 主进程校验窗口/任务/操作归属。只有主动开始录音的主应用窗口得到音频权限；摄像头不获准，内置网页与 HTML 预览不继承该权限。
- 模型安装先校验固定包 SHA-256，再在带所有权标识的目录解包，逐文件校验后原子提升。失败和取消清理本次暂存；启动只回收已退出进程的已标记暂存。卸载拒绝链接、无法确认所有权的目录和额外用户文件。
- 使用前校验模型；缺失、损坏、麦克风拒绝/断开、静音、进程退出和超时均有错误与重试入口。运行中任务不受语音偏好保存影响。
- Kokoro 1.1 有 103 音色：英文女声 0–2、中文女声 3–57、中文男声 58–102。默认 48，提供中英文常用音色。依据官方说明 https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_1.html 。
