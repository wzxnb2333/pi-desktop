# 同聊天唤醒与自动化运行

自动化可以继续指定聊天，或每次在项目主目录、附加目录及独立 Worktree 新建任务。模型、权限和思考程度可单独指定；已有聊天的权限始终作为上限。运行不覆盖该聊天的默认模型或未发送草稿。

触发先写入主进程持久队列，再准备工作目录与初始化。当前聊天忙碌时等待；同一聊天的不同计划串行处理。同一个计划在排队或运行期间重复触发合并为一次，编辑只影响之后的触发。下一次计划时间与触发记录一起保存。

重启恢复未开始的队列；已经准备或执行且结果不明的记录显示中断，由用户检查后重试，不自动重放外部操作。应用退出后不执行调度；保留托盘时继续本地计时。运行历史保留最近 1000 条已结束记录及所有活动记录，删除计划不删除聊天和记录。

自动化页面提供取消单次运行、打开结果、运行配置与失败原因。暂停或删除计划取消尚未开始的记录，已经开始的任务继续；取消运行仅影响该条运行。初始化失败时保存可重试记录，不启动对话模型。

智能体的 manage_automations 工具使用同一调度服务，只管理当前项目或当前独立聊天的计划。只读/计划模式禁止修改；询问模式经主进程确认；没有额外权限通道。当前自动化轮次不能通过该工具等待取消自身，使用停止按钮。
