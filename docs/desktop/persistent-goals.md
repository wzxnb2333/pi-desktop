# 产品持续目标

任务操作菜单创建或查看目标；右上角摘要卡片显示完成数量与状态。目标包含说明和最多 40 条可单独验证的条件，计划步骤独立保存。此页面是 Pi 功能适配，不声称存在同版本逐像素参考。

主进程串行持久化版本、轮次与证据。每轮开始前记录操作标识，完整模型调用及文件快照结束后才启动下一轮。智能体工具 get_goal、update_goal 只能读取和提交已有目标；不能创建、恢复用户暂停的目标或扩大任务权限。完成请求只有在全部条件含证据且本轮正常结束后生效。

- 暂停阻止下一轮，保留当前执行；停止任务同时暂停目标。
- 清除移除目标与验收记录，保留当前执行及聊天历史。
- 修改采用版本检查；改变目标说明重置验收结果，改变某一条件只重置该条件。
- 三次连续失败、三轮未完成新条件、连续二十轮均等待用户处理，避免无进展或错误循环。主动恢复重置计数。
- 应用退出后不执行；重启保留中断轮次并等待主动恢复，不自动重放可能已经产生副作用的请求。
- 归档/回收任务暂停目标；分叉不会复制活动目标。关闭单个窗口不停止任务。

通过本地假供应商验证真实 worker/IPC/UI；无需真实账号或付费模型。验收证据来自智能体提交，界面保留原文供用户复核，不把文字声明自动转换成独立测试证明。
