## 状态与布局

- MCP 测试按服务和配置修改代次隔离；重复保存/测试/任务重连分别设同步守卫，任务重连在主进程合并并复用仓库锁。配置编辑、删除、卸载和任务状态变化不会把旧测试误报为新配置成功；测试工具数组经过共享 schema。断开与 worker 退出保留已发现工具描述，显示为历史；重新连接取得真实结果才更新在线状态。业务状态与恢复是 Pi 适配，不扩展原版几何合同。
- 资源检查与详情使用独立请求代次，资源配置变更触发只读检查，任务流式状态不触发重复扫描。详情区域、创建入口和重试区域管理键盘焦点，不在异步读取完成后重建另一个资源的内容。SDK 源文件检查不执行扩展；worker 初始化的真实加载诊断带实际时间和任务标识，随桌面记录恢复。管理原语沿用既有来源，业务诊断及其状态属于 Pi 适配。
- 摘要与时间线共用消息轮次归属，不依赖 plans 字段插入顺序；旧记录回退和显式清空分别处理。摘要跳转通过 TimelineFocusRequest 指定真实轮次/步骤或审批 ID，只展开目标计划；等待实际有限动画后再聚焦和居中，用户再次操作或任务切换取消定位。窄窗口先关闭覆盖栏，折叠和阅读锚点沿用既有持久化；请求本身不跨重启重放。
- 摘要的 Git 查询与工具完成刷新复用 useGitQuery 的任务/请求隔离，局部失败不污染后续任务。产物路径经编码后交给 useOpenLink 归一，避免同一文件因绝对/相对路径产生两个编辑缓冲，保留 #、% 等真实文件名字符。以上属于 Pi 本地数据和导航适配，没有新增 Codex 服务或独立摘要几何合同。
- 全局布局仍由 ui.update 保存；每任务面板、文件、网页、终端配置、草稿、阅读锚点及 folds 使用 ui.threadPatch 字段合并，保留 ui.threadUpdate 原入口。新增文件、浏览器、Git、会话及 MCP 重试操作经过同一严格 IPC 校验；完整能力见 capability-matrix.md。TimelineItem 有序内容块、结束原因、观测时间及已校验工具详情沿用 conversation-folding.md。
- 拖动时本地显示，pointerup 保存一次；键盘方向键10px步进。窄窗口切换覆盖式抽屉并夹取有效尺寸，不改写宽窗口保存值。浏览器原生视图跟随容器边界，菜单、对话框、审批出现时隐藏网页并交回宿主焦点。
- 菜单保持触发器与浮层独立定位，避免被 main/timeline 裁切；原先的空菜单令牌探针由包含真实行结构的独立样本替代。Pi 使用可键盘激活的 button 承载 menuitemradio 语义，业务动作仍调用原 Pi 接口。
- 确认框保留 Pi 原有的确认按钮初始焦点和不点击遮罩关闭策略；操作按钮外观等同性不代表这些业务交互与原版所有调用点完全相同。
- 搜索结果使用 combobox/listbox 与 aria-activedescendant 管理键盘选择；查找定位只展开命中项的真实祖先，保留其他手动选择。命令、侧栏和对话查找来自 Pi 当前可用能力，没有加载参考端搜索服务。
- 文件链接定位使用 UiThread.fileLocation 的请求标识、相对路径和行列；重复激活可重新定位，同一次请求不因草稿/折叠保存反复夺取焦点。文件读取完成且仍属于选中文件才应用定位；文件缓冲和主进程版本校验保持原有语义。浏览器来源/对话链接由主进程添加标签，renderer 不替换整份标签列表。
- 文件树刷新保留持久展开项，分批加载期间不把深层活动行覆盖为临时父行；原活动项消失时回退至可见父级。其他控件已获得焦点时不抢回焦点。含空格路径先编码为 DOM 关联 ID，保持 aria-controls/aria-describedby 的有效性；目录范围切换和文件定位使用独立字段。
- 文件搜索使用真实主进程扫描器，单次响应至多 200 条/2000 个扫描单元并以 50ms 为分段目标；无命中时也返回进度，后续通过游标继续。每任务独立请求，取消和重试不能复活已替换请求；响应经结构校验并核对任务/请求标识。临时游标不写入桌面 JSON，空闲 5 分钟释放，重启不自动恢复扫描。
- 网页查找结果来自 Electron found-in-page，不从 Pi DOM 估算。findNext 按当前安装 Electron 声明用于初次/后续请求，独立真实网页验证其参数语义；加载尚未结束时延后执行，最终计数与序号仍按请求匹配。清除只交回当前可见网页的焦点；网站不加载 Pi preload，新增 focus 操作继续经主窗口 IPC 校验。
- Git 读取以任务、文件、差异范围或提交标识生成查询键，每次刷新推进请求代次；正在读取的新差异不会继续操作旧补丁。远端分支与本地目标名称分离，创建跟踪分支先确认真实引用；异名上游推送使用完整 refs/heads 映射。合并历史以第一父提交为比较基准，未用无法呈现的 combined diff 冒充空改动。
- 主题默认 seed 与作用域取自 JS，不靠手写静态近似调色板；系统主题同时覆盖媒体查询和实时切换。
- 提取图标保留原始 path。将某个通用 glyph 对应到 Pi 控件属于语义适配，不能由此推断 Codex 每个调用点都使用同一变体。
