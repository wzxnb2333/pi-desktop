## 交付范围

本轮沿用 DesktopBridge、严格 IPC、Pi worker 和本地会话存储，持续补齐已批准的本地工作台计划。保留中文、Pi 名称、现有供应商设置与可配置思考级别。所有新增入口连接本地服务；没有新增 Codex 账户、云服务或浏览器智能体。本文件保留各轮已实现和实际验收的记录，不以局部测试通过代替完整目标审计。

- 右侧统一辅助栏包含摘要、文件、变更和浏览器，终端继续底部停靠。1000×640 使用覆盖抽屉，1280×800 / 1440×940 使用并排布局，响应式切换不写回宽窗口偏好。
- 顶栏摘要显示真实任务状态、当前计划、Git 变更、产物、来源和审批；计划默认单行、按所属轮次保存展开选择。SDK 用量与上下文独立显示，未知数据不估算。
- 会话右键及更多菜单共用真实操作；支持标签关闭/恢复、最近任务、搜索/命令面板、指定消息分叉、工作目录或新 worktree 延续，以及本地回收站。
- 每任务保存草稿、独立附件文件引用、阅读位置、折叠、文件与网页标签。整体撤回 SDK 队列时先完成草稿写入，保留原始技能命令和附件。重启不自动发送草稿或队列。
- 浏览器支持外部 HTTP(S)、多标签、历史导航、查找/缩放、失败重试、用户触发的登录弹窗、上传下载、权限和站点数据管理；任务独立标签共享应用专用持久登录分区。隐藏不销毁，重启按需加载。
- 网页查找增加实际当前序号和前后循环、逐标签查询隔离、中文合成保护、清除并返回网页焦点，以及可配置快捷键。地址栏支持裸域名/本地端口、提交前校验、逐标签编辑草稿和复制实际加载地址。
- 文件树、搜索、标签、面包屑、跳行、路径和外部打开均已接通。内置文本编辑保留 UTF-8 BOM/换行，保存校验版本；并发或外部变更保留编辑缓冲。未保存关闭有确认。
- 对话 Markdown 文件引用支持相对路径、任务内绝对路径、本地 file URI、中文空格和行列；在文件面板定位，保留编辑缓冲及每任务位置。网页和摘要来源进入右侧原生标签，Ctrl/⌘ 点击可使用系统浏览器或外部编辑器。
- 差异支持文件/块导航、暂存/取消暂存、恢复和加入输入。提交使用独立临时索引，仅提交勾选文件的暂存内容，保留其他暂存文件及同一文件的未暂存修改。
- 分支、上游、fetch/pull/push、显式合并/变基、冲突三方内容与编辑解决、继续/中止、取消、历史及 worktree 操作已接通。共用 Git 目录的写操作串行，运行目录变更与活动任务互斥；无自动 stash 或强推。
- Git 分支面板区分真实远端引用和独立本地名称，支持从远端创建跟踪分支；推送保留异名上游。仓库、文件差异、冲突版本及提交历史各自显示加载/错误/重试并隔离迟到结果；历史关闭后恢复焦点，合并提交明确按第一父提交显示差异。
- 终端支持重命名、前后循环查找、真实宽字符/软换行定位、复制/清屏及可配置快捷键；大输出与后台增量连续，查询按终端隔离。隐藏、关闭入口与终止分离；重启只恢复配置，需手动启动进程。
- Skills/扩展支持搜索、详情、来源与加载错误；MCP 支持状态、工具、测试及重试。自动化支持显式时区的日/周/月计划、编辑/历史，待审阅筛选/批量处理/失败重试，通知偏好及跳转。

## 资源管理增量（2026-09-26）
