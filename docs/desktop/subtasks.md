# 可选子任务

默认关闭，在「设置 → 通用 → 启用可选子任务」启用。任务操作菜单中的「管理可选子任务」可填写明确要求、选择共享只读目录或独立 Worktree、选择权限与起始引用。共享目录只读；权限不能超过父任务。产品最多同时运行四个子任务，其余排队。

父任务的最近二十条已完成用户/助手消息作为固定上下文快照，排除工具输出；执行中不追随父任务的新消息。独立 Worktree 从所选 Git 引用创建，不复制未提交内容，等待项目初始化完成再调用模型。子任务只获得所选目录，不继承附加目录写入能力。

父子任务独立运行、停止和关闭窗口。子任务记录保存任务身份、环境、进度、失败原因和最终回答。可打开子任务查看原始过程；完成结果只能主动追加到父任务草稿，保留草稿和附件，同一结果不重复追加，也不自动发送。

智能体只有在全局启用后才看到 manage_subtasks；每次创建/停止都由主进程请求本次确认，即便父任务自动执行也不能跳过。读结果和列表仅限自己的子任务。子任务本身不暴露再次委派工具；用户仍可在界面主动创建下一层。关闭全局开关阻止新委派，不隐式停止已授权任务。

删除或归档父任务取消其活动子任务，保留子任务会话、结果和 Worktree。直接停止父任务不隐式停止子任务。应用退出取消进程；重启把不确定的运行/准备/队列标记中断，必须检查后重新委派，不自动重复。相同创建标识幂等，修改后的委派需要新标识。

初版验证：定向单元 5/5，原生 Electron 4/4（实际本地假供应商协议）。覆盖双语/主题/三种尺寸、运行中委派、真实 Git Worktree 与初始化/文件写入隔离、只读工具、逐次批准与拒绝、结果草稿、关闭窗口、停止、父任务删除、重启和错误引用。fixture 关闭后核对其临时根目录已删除；关闭截图、视频和 trace。

2026-09-29 恢复复核：16 项单元、9 项面板 UI、8 项原生流程通过。状态提交后才发布；停止覆盖在途保存，存储失败不继续执行排队任务。结果与草稿回传凭据原子保存，期间继续输入会提示重新追加，不覆盖新草稿。面板保护失败重试、即时双语及跨任务隔离；完整命令、首次失败及验证边界见 [子任务恢复验收](subtask-recovery.md)。
